🚀 Quick Start

# Install pip install megazord # Initialize and scan GPUs megazord init # Register a model (48GB VRAM, shardable) megazord model add llama-70b 48000 --shard # Load model onto available GPUs megazord model load llama-70b # Start the API server megazord serve --port 8420

📡 API Endpoints

POST /v1/completions        OpenAI-compatible text completion
POST /v1/chat/completions   OpenAI-compatible chat completion
GET  /health                System health check
GET  /gpus                  List all GPUs
GET  /gpus/{hash}           Get GPU by hash
GET  /models                List all models
POST /model/add             Register new model
POST /model/load            Load model to GPU(s)
POST /model/unload          Unload model
GET  /queue                 View request queue
GET  /stats                 Detailed statistics
GET  /params                Current configuration
POST /params                Update configuration
GET  /alarms                Active alarms
POST /alarms/{hash}/ack     Acknowledge alarm
POST /alarms/{hash}/clear   Clear alarm
WS   /ws                    Real-time WebSocket updates

🔄 State Machines (PackML)

GPU States

OFF(0)      → Gray    Offline
STARTING(1) → Yellow  Initializing
READY(2)    → Green   Available
BUSY(3)     → Cyan    Processing
THROTTLE(4) → Yellow  Thermal limit
ERROR(5)    → Red     Fault state

Router States

IDLE(0)     → Stopped
STARTING(1) → Initializing
EXECUTE(2)  → Running ⇄ HELD
STOPPING(4) → Shutting down

Alarm Classes (ISA-18.2)

CRIT(1)  → Red     Auto-shutdown
HIGH(2)  → Orange  Alert + pause
MED(3)   → Yellow  Warning
LOW(4)   → Cyan    Info
