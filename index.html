Core Components

Router (core/router.py)

┌─────────────────────────────────────┐
│ 1. Already loaded? → Use existing   │
│ 2. Single GPU fits? → Use fastest   │
│ 3. Shard across multiple (ADDITIVE) │
│ 4. No GPUs? → Queue request         │
└─────────────────────────────────────┘

Quick Start

# Install pip install megazord # Initialize and scan GPUs megazord init # Register a model (48GB VRAM, shardable) megazord model add llama-70b 48000 --shard # Load model onto available GPUs megazord model load llama-70b # Start the API server megazord serve --port 8420

Usage Example

from megazord import Megazord, M

# Initialize
Z = Megazord(gpu_max=8, api_port=8420)
await Z.init()

# Scan GPUs
Z.scan()  # Detect available GPUs

# Register model (48GB, shardable)
Z.m('llama-70b', vram=48000, shard=True)

# Run inference
result = await Z.r(M('llama-70b'), "Hello!")
print(result.text)
