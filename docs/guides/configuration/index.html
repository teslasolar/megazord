Configuration Reference

All Megazord parameters are environment-configurable with sensible defaults.

System Parameters

VariableDefaultDescription
SYS_NAMEMegazordSystem name
GPU_MAX16Maximum GPUs
API_PORT8420REST API port
DB_PATH~/.megazord/state.dbSQLite path
QUEUE_MAX100Max queue depth

Thermal Parameters

VariableDefaultDescription
TEMP_WARN75Warning temp (°C)
TEMP_THROT83Throttle temp (°C)
TEMP_SHUT90Shutdown temp (°C)

Router Parameters

VariableDefaultDescription
RTR_TIMEOUT300Request timeout (s)
RTR_BAL00=Speed, 1=VRAM, 2=RoundRobin

CLI Configuration

megazord config set sys.api_port 9000
megazord config get
