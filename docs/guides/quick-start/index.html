Quick Start Guide

Get Megazord up and running in minutes.

Prerequisites

  • Python 3.10+
  • NVIDIA GPU(s) with CUDA support
  • pynvml compatible drivers

Installation

# Install from PyPI
pip install megazord

# Or install from source
git clone https://github.com/teslasolar/megazord
cd megazord && pip install -e ".[dev]"

Initialize

megazord init

This creates ~/.megazord/state.db, detects GPUs, and registers them.

Register a Model

megazord model add llama-70b 48000 --shard
megazord model ls

Load Model

megazord model load llama-70b
# Or specify GPUs: megazord model load llama-70b --gpu 0 --gpu 1

Start Server

megazord serve --port 8420

Make Requests

curl http://localhost:8420/v1/completions \
  -H "Content-Type: application/json" \
  -d '{"model": "llama-70b", "prompt": "Hello!", "max_tokens": 100}'
