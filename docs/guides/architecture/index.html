Architecture Overview

Megazord follows ISA-88/95/101 standards for industrial automation systems.

ISA-95 Physical Model

ENTERPRISE: LocalCompute
└── SITE: HomeLab
    └── AREA: GPUCluster
        └── PROCESS CELL: Megazord
            ├── UNIT: Inference (INF)
            │   ├── EM: Router (RTR) ← THE UNLOCK
            │   └── EM: Scheduler (SCH)
            ├── UNIT: Models (MDL)
            └── CONTROL MODULES: GPU[0..N-1]

Core Components

Router (THE UNLOCK)

Cards ADD capacity, don't bottleneck on slowest

1. Already loaded? → Use it
2. Single card fits? → Use fastest
3. Shard across multiple (ADDITIVE)
4. Queue if no capacity
